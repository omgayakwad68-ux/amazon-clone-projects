# Amazon Clone Project

A front-end recreation of the Amazon homepage, developed to strengthen skills in HTML, CSS, responsive layout design, and deployment via GitHub Pages.

## Live Demo
https://omgayakwad68-ux.github.io/amazon-clone-projects/

## Tech Stack
- HTML5
- CSS

## Features
- Responsive navigation bar with branding
- Category grid layout (Furniture, Smartphones, Fashion, Pet Care, Make-up, etc.)
- Structured footer with navigation links

## Key Learnings
- Building semantic, well-structured HTML
- Applying CSS Grid/Flexbox for responsive layouts
- Deploying static websites using GitHub Pages
